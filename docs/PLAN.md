# Cipher Daily: plan and decisions

Codebusters (Science Olympiad) practice site. The main goal is test prep for Division C
teams; a daily puzzle set is secondary. Static site, no backend.

## Work method
- One phase at a time. Each phase ends with tests passing and owner approval.
- Tests for each cipher before its UI. 2a/2b and 4a/4b are separate approval gates.
- Short replies; summarize test results as pass/fail counts.
- Ask before reading more than 2 files or producing large output.
- Commit after each chunk of work. Never push or deploy without being asked.

## Decisions
**Scope**
- Division C only for now; division and level are config values so B can be added.
- All 17 cipher types are built and tagged by season and division. Mock tests, the daily
  rotation and "train weakness" use current-season types only. For Division C in
  2026-27 the legacy types are Caesar, Atbash, Affine, Hill, Pollux and Morbit. Legacy
  types stay in practice (when enabled), have tutorials labeled legacy, and their drills
  are tagged legacy.

**Tech**
- Vite + React + TypeScript, Vitest, localStorage, HashRouter.
- GitHub Pages via the gh-pages branch: `npm run deploy` runs tests, builds and publishes.
- Repo name `cipher-daily` (Vite `base` is `/cipher-daily/`).
- PDFs: `@react-pdf/renderer`, loaded only on export; plain black on white.
- Charts: hand-written SVG. Share/team codes: versioned compressed JSON, base64url, checksum.

**Determinism**
- Seed = mulberry32 over FNV-1a of `cipher-daily:v1:daily:YYYY-MM-DD`, using the
  America/New_York date. Each question slot uses its own derived generator.
- Quote banks are append-only (id = position). `quotes.lock.json` plus a test guard
  existing entries; run `npm run quotes:lock` after appending.

**Quotes**
- English: 741 quotes from public-domain authors.
- Spanish: 99 proverbs and short sayings, plus 120 original sentences (60-120 letters)
  labeled "Original". A test keeps the Spanish letter frequency close to standard Spanish.
- Long verbatim literary passages are avoided; they tripped the output filter.

**Rules and scoring** (configurable; see open items for confidence)
- 2 free errors, then -100 per extra error. Timed question: Aristocrat, bonus
  2 x (600 - seconds), retries allowed without penalty. 50 minutes; teams of up to 3.
- Xenocrypt: Ñ is a separate letter (27-letter alphabet); accents are folded and not
  required in answers; re-encode if the ciphertext has both N and Ñ; K1/K2 alphabets
  with an English keyword (Division B: K1 only).

**Solving and strict mode**
- Strict mode hides the reference panel, frequency counts and auto-fill. The KEY panel
  stays (tests print the key). FREQ reference lists show only if the official sheet has
  them (config switch).
- FREQ tab only on Aristocrat, Patristocrat, Xenocrypt and Homophonic (per-cipher flag).
- Mistake classification is a heuristic; players can relabel it.

**Look**
- Retro computer case (no Apple logos or trademarks), green phosphor screen, scanlines.
  Press Start 2P for headers and menus, VT323 for body text, both self-hosted.
- All theme values are CSS variables in one file. A test enforces WCAG AA contrast.
  Correct, wrong and conflicting letters differ by more than color. Reduced motion
  disables rain, flicker and the boot animation. Below about 700px wide the case is dropped.

**Tutorials**
- One per cipher in `src/tutorials/<cipher>.ts`. Worked examples are generated by the
  cipher engine, and tests check each step against it.
